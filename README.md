# 디스코드 5대5 대전 관리 봇

디스코드 서버에서 5대5 내전을 모집하고, 팀을 나누고, 결과와 승점을 기록하는 봇입니다.
(Node.js · discord.js v14 · SQLite)

## 실행 방법

1. **봇 만들기**: [Discord Developer Portal](https://discord.com/developers/applications)에서 애플리케이션을 만들고 Bot 토큰을 발급받습니다.
2. **서버에 초대**: OAuth2 > URL Generator에서 scope `bot`, `applications.commands`를 선택하고, 권한은 `Send Messages`, `Embed Links`를 체크한 URL로 초대합니다.
3. **설치**
   ```bash
   npm install
   cp .env.example .env   # DISCORD_TOKEN, DISCORD_CLIENT_ID 입력
   ```
4. **슬래시 커맨드 등록** (커맨드 정의가 바뀔 때마다 실행)
   ```bash
   npm run deploy
   ```
   `.env`에 `DISCORD_DEV_GUILD_ID`를 넣으면 그 서버에만 즉시 등록되고, 비우면 전역으로 등록됩니다(반영까지 시간이 걸릴 수 있음).
5. **봇 실행**
   ```bash
   npm start
   ```

데이터는 `data/bot.sqlite`에 저장됩니다. (`DATABASE_PATH`로 변경 가능)

## 사용 흐름

```
/계정 등록 → /대전 참가 (10명) → /대전 포지션 · /팀 등록 (선택)
→ /팀 셔플 → /대전 시작 → /대전 결과 → /승점 조회 · /승점 랭킹
```

## 커맨드

모든 커맨드는 서버 채널에서만 쓸 수 있고, 데이터(계정·대전·승점)는 서버마다 따로 관리됩니다.
오류 메시지는 커맨드를 입력한 본인에게만 보입니다.

### 계정관리

| 커맨드 | 설명 | 비고 |
|---|---|---|
| `/계정 등록` | 이 서버에 계정을 등록합니다. | 탈퇴했다가 다시 등록하면 이전 승점 기록이 이어집니다. |
| `/계정 탈퇴` | 이 서버에서 계정을 탈퇴합니다. | 모집 중인 대전에 참가 중이면 대전에서도 빠집니다. 진행 중인 대전 참가자는 탈퇴할 수 없습니다. |

### 대전관리 - 사용자 관리

| 커맨드 | 설명 | 비고 |
|---|---|---|
| `/대전 참가` | 이번 대전에 참가합니다. | 진행 중인 대전이 없으면 새로 엽니다. 10명이 모이면 셔플 안내가 나옵니다. |
| `/대전 탈퇴` | 대전 참가를 철회합니다. | 모집 중일 때만 가능 |
| `/대전 포지션 <포지션>` | 포지션을 선택합니다. | 탑 / 정글 / 미드 / 원딜 / 서폿 / 선택 해제 |
| `/대전 현황` | 현재 대전의 참가자와 팀 구성을 봅니다. | |
| `/대전 생성` | 새 대전을 엽니다. | 서버당 진행 중인 대전은 1개 |

### 대전관리 - 팀 관리

| 커맨드 | 설명 | 비고 |
|---|---|---|
| `/팀 등록 <레드팀/블루팀>` | 원하는 팀을 직접 선택합니다. | 팀당 최대 5명. 직접 등록한 사람은 셔플에서 제외됩니다. |
| `/팀 탈퇴` | 소속된 팀에서 빠집니다. | 다시 셔플 대상이 됩니다. |
| `/팀 셔플` | 팀을 자동으로 나눕니다. | 참가자가 10명일 때만 가능. 포지션이 겹치지 않는 배치를 우선합니다. |

### 대전관리 - 진행 및 결과

| 커맨드 | 설명 | 권한 |
|---|---|---|
| `/대전 시작` | 10명, 5:5 팀 구성이 끝난 대전을 시작합니다. | 대전 생성자 / 서버 관리자 |
| `/대전 결과 <레드팀/블루팀>` | 승리팀을 기록합니다. 승리팀 전원 승점 +1 | 대전 생성자 / 서버 관리자 |
| `/대전 취소` | 진행 중인 대전을 취소합니다. | 대전 생성자 / 서버 관리자 |

### 대전관리 - 승점 조회

| 커맨드 | 설명 | 비고 |
|---|---|---|
| `/승점 조회 [사용자]` | 승점과 전적(승/패/승률)을 조회합니다. | 사용자를 비우면 본인 |
| `/승점 랭킹` | 이 서버의 승점 TOP 10을 봅니다. | 1승 = 1점, 감점 없음 |

설계 문서(ERD, 셔플 알고리즘 등)는 [CLAUDE.md](CLAUDE.md)를 참고하세요.
