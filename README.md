# 디스코드 5대5 대전 관리 봇

디스코드 서버에서 리그 오브 레전드 5대5 내전을 **버튼으로** 모집하고, 판마다 결과 캡쳐와 승리자를 기록해 승점을 쌓는 봇입니다.
(Node.js · discord.js v14 · SQLite)

## 실행 방법

1. **봇 만들기**: [Discord Developer Portal](https://discord.com/developers/applications)에서 애플리케이션을 만들고 Bot 토큰을 발급받습니다.
2. **서버에 초대**: OAuth2 > URL Generator에서 scope `bot`, `applications.commands`를 선택하고, 권한은 아래를 체크한 URL로 초대합니다.
   - `View Channels`, `Send Messages`, `Embed Links`, `Attach Files`, `Read Message History`
   - 대전 정보 메시지를 올리고 고치고, 종료 시 결과 캡쳐를 첨부하는 데 필요합니다.
3. **설치**
   ```bash
   npm install
   cp .env.example .env   # DISCORD_TOKEN, DISCORD_CLIENT_ID 입력
   ```
4. **슬래시 커맨드 등록** (커맨드 정의가 바뀔 때마다 실행)
   ```bash
   npm run deploy
   ```
   `.env`에 `DISCORD_DEV_GUILD_ID`를 넣으면 그 서버에만 즉시 등록되고, 비우면 전역으로 등록됩니다(반영까지 시간이 걸릴 수 있음).
5. **봇 실행**
   ```bash
   npm start
   ```

데이터는 `data/bot.sqlite`, 결과 캡쳐는 `data/records/<서버 ID>/`에 저장됩니다. (`DATABASE_PATH`, `RECORDS_DIR`로 변경 가능)
이전 버전의 DB 파일은 봇을 켤 때 자동으로 새 구조로 바뀌며, 기존 승점은 유지됩니다.

## 사용 방법

### 1. 관리자: 패널 올리기

관리자가 내전을 진행할 채널에서 `/대전 관리`를 입력하면, **모두가 볼 수 있는 버튼 패널**이 올라옵니다.

| 버튼 | 동작 |
|---|---|
| 📝 대전 등록 | 판 수(1~10판) 선택 → 롤 아이디 입력 → 대전 등록 |
| 🔎 진행중인 대전 조회 | 진행 중인 대전 현황과 참가 버튼을 본인에게 보여줍니다. |
| ✅ 계정 등록 | 이 서버에 계정을 등록합니다. (대전에 참가하려면 필요) |
| 👋 계정 탈퇴 | 이 서버에서 계정을 탈퇴합니다. (기록은 남고, 다시 등록하면 이어집니다) |

### 2. 대전 등록

1. **[대전 등록]**을 누르고 진행할 판 수를 고릅니다.
2. 롤 아이디(`게임이름#태그`)를 입력합니다.
3. 채널에 **모두에게 보이는 대전 정보 메시지**가 올라옵니다. 등록자는 자동으로 참가합니다.
4. 등록자에게는 **본인만 보이는 관리 패널**(대전 시작 / 대전 기록 / 대전 종료 / 대전 취소)이 옵니다.

서버마다 진행 중인 대전은 1개만 등록할 수 있습니다.

### 3. 대전 정보 메시지의 버튼

| 버튼 | 동작 | 보이는 범위 |
|---|---|---|
| 🙋 대전 참가 | 롤 아이디를 입력하고 참가합니다. (최대 10명) | 본인 |
| 🚪 대전 탈퇴 | 대전 참가를 철회합니다. | 본인 |
| 🔎 대전 조회 | 참가자, 포지션, 롤 아이디, 기록 현황을 봅니다. | 본인 |
| 🎯 포지션 등록/변경 | 이번 대전의 포지션(탑/정글/미드/원딜/서폿)을 고릅니다. | 본인 |
| 🛠️ 대전 관리 | 관리 패널을 엽니다. 관리자와 대전 등록자만 쓸 수 있고, 나머지는 "권한 없음"이 뜹니다. | 본인 |

대전 정보 메시지의 참가자 수와 상태는 참가, 탈퇴, 시작, 종료 때마다 자동으로 갱신됩니다.

### 4. 관리 패널 (관리자 / 대전 등록자)

| 버튼 | 동작 |
|---|---|
| ▶️ 대전 시작 | 참가자가 **10명**이어야 시작할 수 있습니다. 시작하면 참가, 탈퇴, 포지션 변경이 막힙니다. |
| 📸 대전 기록 | 판이 끝날 때마다 **결과 캡쳐 1장 + 이긴 사람 5명**을 등록합니다. 등록한 판 수까지 기록할 수 있습니다. |
| 🏁 대전 종료 | 채널에 **모두에게 보이는 종료 알림**을 올립니다. 판별 승리자, 이번 대전 승점, 결과 캡쳐가 함께 표시됩니다. |
| 🛑 대전 취소 | 대전을 취소합니다. 취소한 대전의 기록은 승점에 반영되지 않습니다. |

**승점 규칙**: 판 1승당 1점, 감점 없음. 종료된 대전의 기록만 반영되며, 서버별로 따로 계산합니다.

## 관리자 전용 커맨드

모든 슬래시 커맨드는 **서버 관리자(관리자 권한)** 전용입니다. 일반 사용자의 커맨드 목록에는 보이지 않고, 실행해도 "권한 없음"이 뜹니다. 응답은 `/대전 관리` 패널을 빼고 모두 본인에게만 보입니다.

| 커맨드 | 설명 |
|---|---|
| `/대전 관리` | 이 채널에 버튼 패널을 올립니다. (모두에게 보임) |
| `/대전 참가 [아이디]` · `/대전 탈퇴` · `/대전 포지션 <포지션>` | 관리자 본인의 참가, 탈퇴, 포지션 선택 |
| `/대전 참가자` · `/대전 현황` | 참가자 목록, 팀 구성과 판별 기록 보기 |
| `/대전 시작` · `/대전 종료` · `/대전 취소` | 관리 패널과 같은 동작 |
| `/대전 결과 <승리팀>` | 팀 구성(`/팀`)이 끝난 경우, 팀 기준으로 다음 판 결과를 기록 |
| `/계정 등록` · `/계정 탈퇴` | 관리자 본인의 계정 관리 |
| `/팀 등록` · `/팀 탈퇴` · `/팀 셔플` | 팀 관리 (버튼은 이후 추가 예정) |
| `/승점 조회 [사용자]` · `/승점 랭킹` | 승점 조회 (버튼은 이후 추가 예정) |

## 로그

커맨드, 버튼, 선택, 입력이 있을 때마다 **서버별 로그 파일** `logs/<디스코드 서버 ID>.log`에 한 줄씩 기록됩니다.

```
[2026-11-21 15:30:12] [버튼] 대전 참가 | 홍길동 (hong, 123456789) | 성공 | [입력창 표시] 대전 #3 참가
[2026-11-21 15:30:20] [입력] 대전 참가 - 롤 아이디 입력: Hide on bush#KR1 | 홍길동 (hong, 123456789) | 성공 | 🙋 대전 #3에 참가했습니다. (4/10) / ...
[2026-11-21 15:31:05] [버튼] 대전 관리 | 김철수 (kim, 987654321) | 실패 | ⚠️ 권한이 없습니다. ...
```

형식은 `[날짜] 실행한 커맨드/버튼 | 실행한 사람 | 성공/실패 | 결과 메시지`입니다. 로그 폴더는 `LOG_DIR`, 날짜의 시간대는 `LOG_TIMEZONE`(기본 `Asia/Seoul`)으로 바꿀 수 있습니다.

설계 문서(ERD, 셔플 알고리즘 등)는 [CLAUDE.md](CLAUDE.md)를 참고하세요.
